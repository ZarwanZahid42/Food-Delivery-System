Food Delivery System
A full-stack food delivery system built using Next.js and MongoDB with role-based access for customers, restaurants, and riders. The system provides a fast, interactive, and efficient food ordering experience with real-time data handling.

Features
Role-based access (Customer, Restaurant, Rider)
User authentication and secure login system
Browse and order food from restaurants
Real-time order management system
Automatic restaurant revenue updates
Interactive and responsive UI
Efficient database operations using MongoDB

Tech Stack
Frontend: Next.js
Backend: Node.js
Database: MongoDB
Styling: CSS / Tailwind
Authentication: Role-based system

Project Objective
To develop a scalable and efficient food delivery system that connects customers, restaurants, and riders with real-time order processing and automated revenue tracking.

Future Improvements
Payment gateway integration
Live order tracking with maps
Notification system for order updates
Advanced admin dashboard
Performance optimization for large-scale usage
